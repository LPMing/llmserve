# Candidate directions and evidence gate (2026-10-15)

The search is bounded by the checked-in Qwen3-30B-A3B RTX PRO 6000 BF16
profile, retained topology and actual simulator event semantics. A candidate
is not promoted on network FCT alone. `A` means measured/source-derived,
`B` means a published trace or paper, and `C` means an explicit scenario
assumption. `RESEARCH_LOG.md` records the sequential experiments and failures.

## Closest-work screen

- [NetKV](https://arxiv.org/html/2606.03910v1) already combines cache,
  Decode load and network cost for per-request Decode selection. A new
  receiver scheduler needs a measured increment over this class and over
  load-updating greedy. The current 3P2D gate has none.
- [TokenDance](https://arxiv.org/abs/2604.03143) addresses collective KV
  sharing for synchronized agents; [PagedAttention](https://arxiv.org/abs/2309.06180)
  already supports physical shared prefix blocks. A fork-group paper needs a
  new placement/replication decision and an empirical heterogeneous cohort.
- [SYMPHONY](https://www.usenix.org/conference/nsdi26/presentation/agarwal)
  uses advisory KV prefetch; [HyMCache](https://arxiv.org/abs/2607.18141)
  uses request-level prefix prefetch in a CXL memory rack; and
  [DualPath](https://arxiv.org/abs/2602.21548) changes the storage-load path.
  Tool-gap prefetch alone is therefore not a distinct contribution.
- [PPD](https://proceedings.mlr.press/v306/li26dq.html) and
  [SplitScaling](https://www.ijcai.org/proceedings/2026/568) limit broad
  claims about multi-turn P/D role placement and burst-driven pool resizing.

The public [FreeInference agentic trace](https://huggingface.co/datasets/harvardMadsys/freeinference_agentic_trace)
offers 12,002 sessions and 1,186,582 requests with tool gaps and block-level
prefixes. It spans other served models and includes prompt lengths beyond the
current 2048-token Qwen prefill profile. Using it as a *shape* source is
possible; claiming model-matched Qwen latency without new profiles is not.
