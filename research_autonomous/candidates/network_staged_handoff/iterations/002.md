# Round 16: receiver credit and memory-full falsifier

**Hypothesis.** A real D memory-full path might expose a network-stage
decision that is hidden in cold 1–4P. The simulator could not test this
before repairing its unconditional D allocation after P freed KV.

**Theory and discriminator.** The Llama-3.1-8B 2048-token prompt requires
268,435,456 B of P2D KV per request, 129 D blocks including one first
Decode token, and at least21.475 ms per request on a100-Gb/s cut. A
3,400-block D pool holds at most26 such handoff reservations before
Decode growth; requests27–29 should wait before any P2D flow. If the
last flow is already earlier than P2D-ready, network-only prioritization
has no zero-cost stage headroom in this fixture. All30 arrivals at t=0
are a C stress assumption, not an observed demand process; this is a
correctness test, not a motivation experiment.

**Evidence.** `experiments/run_capacity_repair.py --chunked` and
`experiments/analyze_capacity_repair.py` produced a manifest with config,
source/profile/workload hashes, a960-row rank/rail flow ledger and a
30-row Serving timeline. Exactly30 credits and commits occur. Requests
27–29 incur378 total wait events with first-to-credit waits4.025,
3.429 and0.211 s. All30 complete; P2D bytes total8,053,063,680,
exactly268,435,456 per request. Every flow starts after D credit, all
last flows end before P2D-ready, and the last-flow slack is5.137–5.808
ms. The prior under-capacity case yields identical target ready,
token-2, completion and bytes with/without the credit flag.

**Failure and repair.** The first run disabled chunked prefill. After
Decode preemption, a resumed request needed more than its2,048-token
budget and its FCFS waiting queue never advanced. The run was
interrupted and retained as `INVALID_INTERRUPTED`; no result from it is
used. `_schedule_waiting` now fails fast on an unsplittable request
larger than the full token budget, and a regression checks the error.
The valid rerun enables chunked prefill and verifies progress.

**Decision.** The opt-in credit repairs a causal correctness hole. The
uniform simultaneous burst has no strong-baseline scheduling distinction,
no exposed last-flow barrier and an intentionally overloaded2P:1D
ratio. Therefore `NO_GO` for a network-stage paper claim in this
fixture. Reopen only with source-backed stable demand and a theoretical
≥10% margin after capacity-aware FIFO/SRPT/EDF and P:D ratio choices.
