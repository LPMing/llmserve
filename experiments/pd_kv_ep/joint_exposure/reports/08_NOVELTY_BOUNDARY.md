# Novelty boundary

Status: CONDITIONAL / NOT A NOVELTY CLAIM. The motivating phenomenon has not
yet passed the natural-exposure and integrated-serving gates, so a novelty
claim would be premature. If a candidate passes, compare the specific joint
mechanism against MFS, Nuska, coflow/laxity-aware scheduling, stage-aware
communication scheduling, DistServe, Mooncake, Splitwise, DualPath, NetKV,
and Libra. The discriminating claim must be that serving scheduling changes
which barriers are exposed and network scheduling serves the remaining
exposed barriers, with measured joint gain beyond either single oracle; a
generic low-slack priority rule is not sufficient.
